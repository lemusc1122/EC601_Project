# Feedback submissions

Feedback submitted from the prototype is saved here as a Markdown file with an
submission time, screen context, and the text entered by the user.
When `QCB_FEEDBACK_API_URL` is configured, the app also sends the feedback to
the HTTPS backend, which creates a Markdown file in this directory in the
`lemusc1122/EC601_Project` GitHub repository. The local file remains as a copy.
Without a configured endpoint, the submission stays local.
