MODEL-BASED TRANSLATION ROUND-TRIP STATISTICS

Scope
  14 representative primary-interface strings per language, selected from the
  active Spanish and Arabic UI catalogs in prototype.py. This is a sample, not
  a full audit of all 53 top-level UI strings or the longer educational copy.

Method
  I translated each original string into English, then translated that English
  rendering back into its starting language. This was generated by one language
  model in one session, without an independent translation engine or human
  reviewer. Counts below compare Unicode word tokens (case-folded, punctuation
  ignored) and Unicode code points using Levenshtein edit distance. Placeholders
  such as {value} and {url} are included in the token check.

Spanish sample (14 strings)
  Original word tokens:                 85
  Back-translation word tokens:         90 (+5; +5.9%)
  Original/back characters (strings concatenated): 563 / 615 (+52; +9.2%)
  Word-token edit distance:              32 (37.6% of original token count)
  Mean word-token edits per string:      2.29
  Character edit distance:              182
  Exact normalized rows:                  0 / 14
  Rows preserving all placeholders:      14 / 14

Arabic sample (14 strings)
  Original word tokens:                 61
  Back-translation word tokens:         66 (+5; +8.2%)
  Original/back characters (strings concatenated): 362 / 397 (+35; +9.7%)
  Word-token edit distance:              35 (57.4% of original token count)
  Mean word-token edits per string:      2.50
  Character edit distance:              107
  Exact normalized rows:                  1 / 14
  Rows preserving all placeholders:      14 / 14

Interpretation and limits
  The back-translations mostly paraphrase the same short UI instructions. The
  token differences show wording drift, with more lexical variation in this
  Arabic sample. They do not measure correctness: synonyms, grammatical
  differences, Arabic clitics, and word segmentation can raise edit counts even
  when meaning is preserved. Conversely, a small edit count cannot prove that a
  translation is accurate. This self-round-trip is useful for surfacing strings
  for human review, but it is not an independent quality score.
